CSCI 544 / TEAM 17 / PAPER, PROBLEM AND PROPOSED SOLUTION

Does dynamic trust better predict escalation?

REFERENCE

MatrAIx: Simulating the World with 8.3 Billion Persona Agents
Li et al. (2026), arXiv:2608.04205

Large persona simulations for evaluating AI systems. We test one piece those personas usually freeze: trust while the conversation is still going.

THE PROBLEM

  • A static agent keeps one trust score, so its tone does not change when the partner is dismissive.
  • People lose patience faster than they regain it.
  • If both agents stay polite, a blind judge can call the thread civil even when the real conversation later had a personal attack.

DATASET: CGA-WIKI

  • 4,188 Wikipedia talk-page conversations (Zhang et al., ACL 2018).
  • Two speakers. Agents see only the first 3 turns, cut off before any attack.
  • Label: the real thread later had a personal attack, or it did not.
  • Each attack thread is paired with a civil one from the same page.
  • Later human turns and the label stay hidden from the agents.

OUR COMPARISON

  • Same opening, personas, model, prompt, and length in both arms.
  • Static: trust stays at the value set by rating the opening.
  • Dynamic: the listener updates trust after every new message, and the next reply follows that mood.
  • A blind judge scores the dialogue only. We then compare those scores with the real label.
